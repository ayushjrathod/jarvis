# Tasks area — context

Vault conventions this area relies on:

- `vault/tasks/` — one markdown file per task (schema in SKILL.md).
- `vault/briefs/YYYY-MM-DD.md` — daily briefs written by the daily-brief agent.
- `vault/notes/` — the user's free-form notes; read-only for this area.

The user is the only person using this system; there is no assignee concept.
Dates are ISO (YYYY-MM-DD), timezone is the machine's local time.

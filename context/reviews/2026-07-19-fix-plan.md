## Unit A — Trust-boundary tool enforcement (H1 + H2) ★ do first

The guardrail must be mechanical, not conventional. Two entry points:

**A1 — external `metadata` must not widen tool scope or budget.**
`dispatcher/service.py:351-355,378-379`, `dispatcher/main.py:120`,
`dispatcher/runner.py:117-122`.
- Add a notion of *trusted* task creation. Internal callers that legitimately
  pass `allowed_tools`/`max_cost_usd`/`resume_session_id` in metadata:
  reflection, notify-gate, memory-consolidate, automation-parse, graph-extract,
  graph-reconcile, and any server-spawned agentic task. External sources: `api`,
  `queue`, `voice`, `ui`, `screen:*`.
- For non-trusted tasks: ignore `metadata["allowed_tools"]` (fall back to the
  configured per-task-type allowlist) and **clamp** `max_cost_usd` to the
  configured cap (never raise it). `resume_session_id` from an external caller
  should also be ignored.
- Implement as a `trusted: bool` param on `submit()` (default False), set True
  only by the internal spawn paths; or intersect requested tools with the
  configured allowlist so external can *narrow* but not *widen*.
- Test: `POST /task` metadata with `allowed_tools:["Bash"]` + `max_cost_usd:100`
  from source `api` → built cmd has no Bash grant, has `--disallowedTools Bash`,
  and budget == configured cap. Internal spawn still passes its metadata through.

**A2 — validate SKILL.md frontmatter `allowed_tools` at load time.**
`dispatcher/areas.py:78` (where `allowed_tools` is read from frontmatter).
- On load, reject/strip `Bash` and unscoped `Edit`/`Write` (i.e. `Edit`/`Write`
  with no path filter) unless the area name is in a config allowlist
  (new `security.privileged_areas: []` in config.yaml, default empty).
- Log a warning when a grant is stripped. This means even if a reflection/learn
  run writes Bash into an area's frontmatter (H2 chain), it is inert at load.
- Test: an area file with `allowed_tools: [Bash, Read]` not in the allowlist →
  loaded tools == `[Read]` + a warning; same area in `privileged_areas` keeps Bash.

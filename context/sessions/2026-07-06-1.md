## Bugs found by the smoke test (both fixed)

1. Silero v5 ONNX requires 64 context samples prepended per 512 frame —
   without it, 0/49 speech frames detected. (vad.py keeps rolling context.)
2. openwakeword 0.4.0 reset() leaves stale mel-spec features → wake word
   re-fires on silence after a detection. Engine reset() flushes 2s of zeros.

Also: openwakeword pinned to 0.4.0 by Python 3.14 (no tflite wheels for
newer); 0.4.0 bundles hey_jarvis ONNX so no downloads needed.

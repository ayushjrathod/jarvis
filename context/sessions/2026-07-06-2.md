## Two hard-won lessons (both fixed + regression-tested)

1. **`Write(path)` allowedTools rules are silently ignored** by the CLI; only
   `Edit(path/**)` rules gate file writes (they cover Write/MultiEdit too).
   Symptom: agent reports success, no file written. Probe-verified.
2. **Exact-substring triggers miss spoken phrasing** ("mark the domain task as
   done" ≠ "mark task"). areas.py now matches trigger words as in-order
   subsequences; SKILL triggers rewritten compact ("mark task done").

Also: two stale-dispatcher-restart incidents (kill by PID + verify port free
before restart — pkill -f is a footgun, it can match its own shell).

# Session 16 (2026-07-23): Spotify media control by voice

User asked for "play spotify songs using hey jarvis". Planned + implemented in
one session; plan doc at `~/.claude-per/plans/i-want-to-add-wiggly-gadget.md`.

## Decisions

- **Search via client-credentials Web API, playback via MPRIS** (user picked
  this over MPRIS-only and over full user OAuth). App-only auth: no redirect
  flow, no refresh tokens, **no Premium requirement** — the desktop client does
  the playing, the Web API only resolves a name to a `spotify:track:` URI.
  Researched mid-session: Premium **Student is a full Premium tier** (the
  "student 403" forum threads are client-credentials/free-account errors, not a
  student-plan limitation), so the OAuth path stays open if the user later
  wants their own playlists/liked songs — that's the one thing this design
  gives up.
- **Deterministic + LLM fallback** (user's choice). The fallback is a
  `media-parse` quick task that returns SEARCH WORDS ONLY; the action is always
  executed by deterministic Python. Explicitly **not** an area: an area would
  need Bash to reach D-Bus, defeating the Phase-13 trust boundary.
- **No new dependencies**: jeepney (already approved for the ask-screen portal)
  and httpx.
- Divert placed **after** the automations divert in `POST /task` so
  "every morning play jazz" still becomes a standing automation.

## Files

- **`dispatcher/spotify.py`** (new) — `detect()` pure intent parser with a

  launches the flatpak client; client-credentials token cache + `search()`;
  `run_intent()` (never raises — always a spoken sentence) and `state()`.
- `dispatcher/service.py` — `media_command()` + `_parse_media()`;
  `media-parse` added to `NO_CONTINUITY_SOURCES`.
- `dispatcher/main.py` — media divert in `POST /task`, `POST /media`,
  `GET /media/state`, `MediaIn` model.
- `dispatcher/notify.py` — `media-parse` in `NEVER_SURFACE_TASK_TYPES`.
- `dispatcher/config.py` + `config.yaml` — `dispatcher.media` block
  (empty/absent = feature off, the automations convention).
- `scripts/setup_spotify.sh` (new, executable), `scripts/doctor.sh` (media
  section), `.gitignore` (`data/spotify.json`).
- `tests/test_media.py` (new, 57 tests).

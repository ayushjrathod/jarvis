## What landed this session (E, F, G)

### Unit E — dispatcher robustness
- **M1** `dispatcher/main.py`: `/stt` body cap (`MAX_STT_BYTES` 25MB, checks
  Content-Length then actual len → 413). Added a `guard_origin` HTTP middleware
  — a *present, non-local* Origin on POST/PUT/PATCH/DELETE → 403; absent Origin
  (curl, jarvis client, MediaRecorder) and loopback/self Origins pass. Existing
  tests send no Origin, so unaffected.
- **M2** `quick.py`+`service.py`: thread `procs`/`task_id` into `quick.stream`
  so the CLI subprocess registers in `svc.procs` (cancel/barge-in can kill it,
  mirroring the agentic runner); `stream_quick` gained `_is_cancelled` guards at
  the retry-loop top and before the final `set_task_status` so a cancel isn't
  clobbered back to done, and no fresh turn spawns over a cancelled task.
- **M3** `db.py`: `BUSY_TIMEOUT_S=15`, applied as the connect timeout and a
  `PRAGMA busy_timeout` on every connection — WAL contention waits at SQLite
  instead of erroring at the 5s driver default, so a settle write can't strand
  a task 'running'.
- **L1** `db.py`: `add_fact` now does fact + FTS + entity upserts + links in one
  `_conn()` transaction (`_upsert_entity(c, name)` cursor variant); a mid-way
  failure rolls back — no orphan fact.
- **L2** `runner.py`+`quick.py`: `reap_reader()` helper always awaits/cancels
  the concurrent stderr drainer in `finally`; `await proc.wait()` after `kill()`
  in the quick timeout path.
- Tests: +9 (test_ask_screen M1, test_dispatcher M2 + reap_reader,
  test_semantic_graph L1 atomic + M3 pragma). 241 → 250.

## ⚠️ Commit-time note for ui/dist (gitignored, force-added)
`ui/dist/` is in `.gitignore:19`; the served snapshot is force-added. This
rebuild left git showing: `D` on the two OLD assets, `M` on `index.html`, and
the NEW assets **untracked+ignored**. Committing as-is would ship a dist that
references assets not in the repo → broken dashboard on checkout. When you
commit the UI change, force-add the new bundle:
```
git add -f ui/dist/assets/index-lkUaqwu2.js ui/dist/assets/index-A83EmG_w.css
git add ui/dist/index.html            # picks up the D on the old assets too
```
(Same pattern every prior "ui/dist rebuilt" commit used.)

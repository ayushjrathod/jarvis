# Session 14 — 2026-07-22 — docs page at /system-docs

## Ask

"Create a docs page at the port we serve the dashboard on, /docs."

## Decisions (user-chosen in plan mode)

- **Path is `/system-docs`, not `/docs`** — FastAPI auto-mounts Swagger UI at
  `/docs` (`create_app` never sets `docs_url`), and the user chose to leave it
  there rather than move or disable it.
- **Content = both** a human user guide and an HTTP API reference, one page.
- **Built as a page inside the existing SPA**, following the ask-screen
  pattern, rather than a standalone static HTML file or a runtime markdown
  renderer (a renderer would have meant a new npm dependency).

## Files touched

- `dispatcher/main.py` — factored the `/ask` index lookup into a local
  `_spa_index()` helper and added `GET /system-docs` returning the same SPA
  shell. Needed because the `StaticFiles(html=True)` mount at `/` only falls
  back to index.html for directories, so every client-routed path needs a
  route of its own.
- `ui/src/main.jsx` — the pathname ternary became a `PAGES` map
  (`/ask` → AskScreen, `/system-docs` → Docs, else App).
- `ui/src/docs/content.js` (new) — all documentation as data: a `guide` array
  of sections (`{p} {note} {code} {list} {table}` blocks) and an `endpoints`
  array grouping all 26 dispatcher routes. The first section is a **Quick
  start** cheat sheet (URLs, hotkeys, the four commands worth memorising, a
  curl example), added on user request after the first pass. Sourced from README.md, the
  CLAUDE.md operational notes and the route signatures themselves.
- `ui/src/Docs.jsx` (new) — renderers for those block shapes, sticky TOC,
  endpoint tables with method chips, a `/health` dot. No SSE subscription.
- `ui/src/styles.css` — a `/* Docs page */` block using only the existing CSS
  variables; two-column layout collapsing at the same 800px breakpoint as the
  dashboard grid.
- `ui/src/App.jsx` — a "docs →" link in the dashboard header (the docs page
  would otherwise be undiscoverable).
- `tests/test_ask_screen.py` — `test_system_docs_serves_html` and
  `test_swagger_still_owns_docs` (guards the path choice from regressing).
- `README.md` — a Docs subsection under Dashboard.

## Verification

- `.venv/bin/python -m unittest discover tests` → **263 tests, OK**.
- `npm run build` clean; dispatcher restarted; `/system-docs` 200, `/` 200,
  `/docs` still serves Swagger.
- Headless chromium renders checked at 1250px (full page, guide + all six
  endpoint groups) and at 520px (nav collapses to a wrapped row, sub-links
  hidden, tables scroll).
- Cold deep-links (`/system-docs#api`) needed an explicit `scrollIntoView` on
  mount — the browser resolves the hash before React has rendered the
  sections. Fixed in `Docs.jsx`.
- **Not screenshot-verified: the dashboard itself.** Headless chromium never
  finishes loading `/` because the `/events` SSE stream stays open, so the
  screenshot never fires. Pre-existing behaviour, unrelated to this change;
  the route returns 200 and the bundle builds.

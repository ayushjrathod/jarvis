## Method

speakers, screen or input devices.**

Each was told to verify by execution and label anything unproven UNVERIFIED. They
did, and the proofs are the reason to trust the report: a generated corpus of
**187,770 sentences** for parser collisions, 38 hostile FTS5 inputs, 25 URL-scheme
payloads, real queries against a copy of `data/mission.db`, a headless chromium
driving a scratch build byte-identical to `ui/dist`, DST simulated across
spring-forward and fall-back, and a 5 MiB stream line fed through a fake CLI.

Slices, in order run: dispatch core · memory/graph · personal OS · learning loop
+ areas · parsers/safety plane · voice · dashboard UI · ops/config/vault.

## What it found

Detail is in the review doc; the shape of it:

- **The vault is on a public GitHub repo** — `USER.md` (written nightly from
  every episode), `MEMORY.md`, tasks and 36 briefs, 42 tracked files, and
  `vault/inbox/` is not ignored. Re-confirmed by hand: `"private": false`. The
  briefs look deliberately committed, so this is a decision, not a plain bug.
- **`Edit(**)` survives the H2 sanitizer** — `_is_privileged_tool` reads "has a
  parenthesis" as "is scoped". Proved end-to-end: a reflection run that read
  attacker-controlled text can write an unscoped grant into a SKILL.md, and the
  next ordinary task — or the 07:30 brief timer — runs with repo-wide write,
  which reaches `config.yaml` and buys real Bash on the run after.
- **Three ways Jarvis goes deaf while systemd reports it healthy**, including
  one where `--mode both` — the mode the service runs — can never execute its
  own "exit so systemd restarts us" path.
- **Both nightly memory agents are told today is yesterday** (UTC `{{DATE}}`
  against local `OnCalendar` at UTC+5:30), so every date written into the memory
  blocks and every `kg_facts.valid_at` lands a day early.
- **The desktop and media parsers claim ordinary English and file it `done`** —
  `open tasks`, `run migrations`, `put on the kettle` — because every executor
  failure is reported as success.
- **The BM25 leg of hybrid search returns zero rows for any natural-language
  question**, and **degraded mode is still bypassable** — this time by
  contractions, since `what's` survives as a "content word" and FTS5 splits on
  the apostrophe. The swallow question from CLAUDE.md returns three unrelated
  briefs.
- **Events are dropped at both ends on healthy connections** — the server bus
  evicts the newest event, the client's single `lastEvent` slot collapses
  batched ones — and nothing reconciles, because the only re-seed is on
  reconnect.
- Two quiet regressions: **the morning brief notification has been gone since
  08-03** (the quiet path never submits a task, so it never reaches the gate),
  and **the dashboard task checkbox has never worked** (`toggle_task` writes the
  file back byte-identical and returns success).

## Reference repos: what is actually worth taking

Full table in the review doc. The highest-value four:

1. **hermes `tools/skills_guard.py`** — an *agent-created* trust tier, statically
   scanned before the skill takes effect. Twenty lines of it closes the
   sanitizer hole, the name-shadowing and the all-matching trigger at one seam.
2. **Claude-Code-Agent-Monitor `server/lib/security.js`** — the Host-header
   anti-DNS-rebinding guard, which is *exactly* the last open code item STATE.md
   has been carrying.
3. **openjarvis `agents/executor.py` + `errors.py`** — settle the run in a
   `finally`, and classify errors with an explicit default branch. Its docstring
   documents the identical stranded-`running` bug we have.
4. **khoj's notify shape** (patterns only, AGPL) — the gate returns a structured
   *decision* and the spoken text is rendered from the task's own output, so the
   gate model never authors user-facing prose. That closes the injection channel
   outright rather than hardening a prompt.

## Two lessons worth keeping

- **A negative test proves nothing unless its inputs can only fail for the
  reason being claimed.** Session 29 found one; this review found two more.
  `tests/test_offline.py:12`'s fake tokenizer keeps the apostrophe — the
  opposite of FTS5 — so it could never have caught the contraction bypass, and
  `test_ordinary_imperatives_are_not_desktop_commands` uses only article-led
  inputs, so it exercises the article rule and nothing else while appearing to
  pin the app-name rule.
- **A fix applied to one sibling must be applied to the others.** Four findings
  are the same bug in an unfixed twin: the `.get(key, default)` fail-open in
  `automations.py` (fixed in `inbox.py` on 08-08), the stream leak in
  `audio.py` (fixed in `MicStream` and `_output_stream`), the confirm-banner
  staleness reached by voice instead of by id (fixed for id on 08-11), and the
  `graph_extracted_at` clipping bug inherited from the `consolidated_at`
  version it replaced.

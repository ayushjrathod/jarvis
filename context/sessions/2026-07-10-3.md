## Diagnosis (journal + mission.db)

- Wake → STT → dispatcher **all worked**: every "are you there?" has a
  `done` row in SQLite with a sensible reply. The user just never heard it.
- Default sink = JadeAudio JA11 earphones at **27% volume** — replies were
  playing into unworn/quiet earphones. TTS→Player probe via the exact
  runtime path returned ok=True.
- **Real crash found**: 10:20:03 IST — barge-in fired mid-reply (echo or
  user speech), `brain.cancel()` killed the task server-side, the in-flight
  SSE stream then raised an unhandled httpx transport error out of
  `handle_utterance` → process exit 1 (systemd restarted it).
- **ydotool is not installed** — CLAUDE.md's "ydotoold already runs as a
  user service" was stale. Dictation typing is blocked on it.

  tune from near-miss scores, or train a custom openWakeWord model on the

  `play_beep_async` is now a wrapper — beep remains the fallback when the
  phrase list is empty). All five auditioned candidates synthesized cleanly

  (echo) worse than the sine beep did — earphones fine.
